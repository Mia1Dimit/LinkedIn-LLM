You can find example responses that i ran through postman in the folder Example_Snapshot_calls. Read all the files included in the folder.

To build the first script we need to take into account how the phase 1 works. It parses csvs and then chunks them embed them using ai and then loads them into chromadb. So our output needs to be compatible to the input of parse_companies_v2 where instead of parsing csvs it will most probably parse jsons. Read parse_companies.py

But important is that jsons has to be complete. from day 0 to the last date available of Snapshot API. Run the script to verify it works correctly.
